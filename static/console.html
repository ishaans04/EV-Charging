Understand the model & complexity

Each request is a fixed interval [start, deadline). Deadline = start + duration; touching endpoints do not overlap. Profit = round(energy × (tariff × surge − energy cost)). Ports are identical; all bookings are known in advance.

DP sorts by finish time and finds predecessors with binary search: OPT(j) = max(OPT(j−1), profit(j) + OPT(pred(j))). Time O(n log n), space O(n). DP supports one port.

Flow builds a node per distinct time, zero-cost idle arcs of capacity k, and request arcs of capacity 1 and cost −profit. A DAG pass initializes potentials; successive Dijkstra searches route k units. Time O(k n log n), space O(n).

Greedy rules use first-fit port admission with minute bitsets. B is the number of machine words spanning the 1,440-minute day; time O(n log n + n k B), space O(n + k B). Interval coloring assigns the chosen set to physical ports.

Subset enumeration takes O(2ⁿ n log n); branch and bound takes O(2ⁿ n log k) in the worst case. The UI limits both to 14 requests. Flexible start windows, online arrivals, grid limits and fairness constraints are outside this fixed-slot model.
